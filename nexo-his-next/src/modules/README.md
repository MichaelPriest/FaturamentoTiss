# Módulos

Cada diretório deste nível é um bounded context. Um módulo aprovado contém schemas Zod, casos de uso, repositórios Supabase, componentes e testes próprios. Os contextos previstos são: core, auth, usuários, estrutura, pacientes, profissionais, convênios, atendimentos, agenda, triagem, prontuário, prescrição, exames, internação, enfermagem, farmácia, estoque, faturamento, TISS, glosas, financeiro e relatórios. Diretórios são criados junto da primeira implementação real, evitando scaffolds vazios apresentados como funcionalidade.
